# /closeout — PROME closeout (order of operations; rules live in `PROME/CLOSEOUT.md`)

**This is a RUNNER over `PROME/CLOSEOUT.md`, not a replacement for it.** Every step below maps to a CLOSEOUT.md chunk and carries no rule of its own. Byte thresholds, crc recipes and the reasons live there — open it when a trigger fires.

0. **Tier + pre-closeout (CLOSEOUT "When to run" / "Skip rules" / Pre-closeout):** read them, pick the tier, say it to Will in one line. `date` (or the NOW: stamp) before every timestamp you write. **If this session spawned named subagent desks (ANY tier, Bounce included):** send each live one the "run your closeout per your own protocol" ping, verify **idle + last delivery committed**, and log the final touch in `PROME/state/ORCH_LOG.tsv` — a desk released without its own closeout leaves a stale header over its newest content (PAT-112).
1. **Mechanical gate first:** `python3 PROME/tools/prome_gate.py closeout` — BLOCKING fails are dispositioned before any prose. It runs DOCKET-today, orphan_check, WILL_QUEUE reconcile, boot↔closeout symmetry, byte budgets. Read the advisories.
2. **State files, owner order (Chunk 1):** WILL_QUEUE (rows ruled today → RECENTLY DONE with anchors; new Will items registered; reconcile stamp = ONE stamp) → GATES/DOCKET (rows fired/resolved/re-dated) → **`ACTIVE_DECISIONS.md` surgical if any decision moved** (boot pairs with it — unwritten = silently stale) → SCRATCH full rewrite (★ NEXT SESSION first; errors ledger; cautions; operator card FROM THE MIRROR; calendar = DOCKET view) → STATUS header (one-line pointer-weight headline; spine-audit stamp) → HANDOFF entry (rotate the oldest if >5; crc32 **recomputed from the archived bytes**, never read off the banner) → HEARTBEAT only if a market/system event or Will decision changed it.
   - **Flow rules (Chunk 1):** `wc -c` STATUS and ACTIVE_DECISIONS — either ≥ **24,412 B** (75%) ⇒ rotate oldest history verbatim into `PROME/archive/` until < **22,785 B** (70%), crc32 round-trip verified, recorded in the commit.
   - **Blind cold-reader before the commit ships:** ANY rotation pass under a byte flow rule, and ANY HEARTBEAT re-base ⇒ run **`/coldread`** on the rewritten surface and grade it. The author knows the answers; only a cold reader detects a dropped guard.
   - **State files carry behavior-language, not commit hashes** — hashes decay inside 48h. Hashes go in the report to Will (step 6), not into SCRATCH/STATUS/HANDOFF.
3. **Memory (Chunk 2):** `memory/YYYY-MM-DD.md` daily log. Auto-memory only for an unpredictable-trigger lesson; if the MEMORY.md byte check reads ≥75%, demote to cold until <70% (never delete), slug-conservation proven in the commit. `python3 scripts/memory_index_check.py --strict --slug <name>` per new slug; `bash scripts/check_memory_length.sh`.
4. **Residuals (Chunk 3, trigger-gated — walk the list, don't recall it):** consumer_check if a figure was superseded · **canonical doc changed ⇒ Mirror-Map walk, `consumer_check.py --mirror-map --old <TOKEN>`, BEFORE commit** · **doc retired/created ⇒ update the Boot Trust Stack (`PROME/SYSTEM.md`)** · **DOCKET row changed ⇒ `firetime_check.py` on citing artifacts (DATE flag = full logic re-read)** · ledger_staleness nudge if STATUS moved without its ledgers · claim_check weekday on DOCKET/GATES/WILL_QUEUE/STATUS · **spine-audit stamp >7d ⇒ run it or hand it to next boot in SCRATCH** · **autonomy change ⇒ AUTONOMY.md log + propagate to `PROME/CLAUDE.md` Ask-First (the surface boot actually reads)** · **sub-agents ran ⇒ diff their outputs against PROME owner docs and promote unpropagated facts before commit** · **new external surface ⇒ `reference` auto-memory** · research retirement (>60d, unread, unreferenced → archive) · `.claude/agents` + `.claude/skills` root↔PROME parity (gate advisory).
5. **Git (Chunk 4):** every commit through `python3 PROME/tools/commit_check.py commit -F <msgfile> -- <exact paths>` (message via the Write tool, never inline — the git guard reads prose as commands; the same applies to ANY prose that quotes a git command — DOCKET/WILL_QUEUE row text, packet bodies — write it via the Write tool or inside a heredoc, which the guard strips). Root/shared docs only on Will's word, cited verbatim in the message. Then `bash scripts/safe-push.sh` — the receipt is `Pushed. CONFIRMED: HEAD <sha> is on origin/master (fresh fetch).`; anything else is not a receipt. Non-ff ⇒ `git pull --rebase --autostash` after checking incoming paths don't overlap dirty paths; never force.
6. **Report to Will:** what landed (hashes here, not in state files), what's owed at next boot, open ⚖️ rows by number, the push receipt line verbatim.
7. **`PROME/CLOSEOUT.md` § Closeout-class fleet memories** (~1.5 KB, 5 one-liners) — read them on any Standard+ closeout; they have no other carrier.
