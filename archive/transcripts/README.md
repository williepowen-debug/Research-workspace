# Sub-Agent Transcripts

This folder contains readable transcripts of sub-agent interactions.

## Structure
```
transcripts/
├── labor/
├── carl/
├── henry/
├── sam/
├── reginald/
└── liquid/
```

Each transcript is saved as markdown for easy reading on GitHub.

## Format
- Filename: `YYYY-MM-DD_HH-MM_[task-summary].md`
- Contains: Task, agent response, tool calls, runtime stats
