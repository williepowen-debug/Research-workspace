## The defect, in its own terms
`argus_contract.freeze()` requires every path in the inventory (changed since baseline, committed or pending) to be delivered, evidenced, observed with a human basis+quote, or attributed by commit. The verify (repaired today, WQ-448 re-scoped) already treats a pending foreign path as advisory. The freeze does not: a file another desk has pending at the instant of freezing must be hand-classified, and with a live fleet the set changes faster than a human can write it. The two halves of one instrument disagree about the same path; the freeze is the stricter half for no safety gain, because the verify would read that path as advisory a second later anyway.
