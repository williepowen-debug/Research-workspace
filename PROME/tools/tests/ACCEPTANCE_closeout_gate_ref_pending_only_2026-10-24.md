## Design (one change to one artifact, `PROME/tools/argus_contract.py` `verify()`)
The `--ref` / `--snapshot` forms apply `foreign_pending()` to a path only when ALL of these hold; otherwise the path stays `UNCLASSIFIED` (strict):
- **pending-only:** `state['pending']` non-empty AND `state['commits']` EMPTY (no commit touching the path in baseline..HEAD) — so a path in baseline-to-target history is never advisory at this form (the separate `changes(baseline, target)` loop keeps checking history and snapshot paths strictly, unchanged);
- **outside the delivery commit:** not among the delivery's ACTUAL paths (a pending path that is also in the delivery commit has a commit in baseline..HEAD, so the previous condition already excludes it; the actual-paths loop still errors on any actual path outside the delivered set — unchanged);
- the existing `foreign_pending()` predicate: not DELIVERED, not a `never_advisory` file (perimeter, ignore/attribute files), lane not OWNED under the PINNED rules, no PROME authorship evidence.
Everything else in `verify()` is byte-identical: CHANGED-SINCE-REVIEW on delivered content and current evidence, historical-dependency pins, `UNREVIEWED DELIVERY PATH`, `UNREVIEWED ACTUAL COMMIT PATH`, `UNCLASSIFIED SNAPSHOT PATH`, the observed-attribution recheck, rc semantics (advisories ride rc 0 only when `errors` is empty).
