### Key Structural Insight for Deck Design

Batch 2 reveals the thesis has a **convergence problem** — in the best possible way. All four ZHAO anchors trace back to Hormuz through independent pathways. BRENT's supply math and HAWK's military facts describe the same event from different lenses. This means:

**One root cause (Hormuz closure) → four independent transmission channels → same outcome (rates stay high, consumer breaks, banks stressed)**

That convergence IS the slide. If an audience member says "but what if Japan stops selling?" the answer is: there are three other sellers, all for different reasons, all pointing the same direction. The thesis doesn't depend on any single anchor — it depends on the structural reality that all four are active simultaneously.

### Key Structural Insight for Deck Design

Batch 3 reveals the thesis has **two independent detonators**:

1. **The Hormuz chain** (BRENT → HAWK → HENRY Hamilton timeline → consumer/bank stress)
2. **The Japan chain** (SAM → carry unwind → VIX spike → forced selling → global contagion)

These are causally linked (Hormuz drives Japan's energy costs, which accelerates yen weakness and repatriation) but can trigger independently. Even if Hormuz reopened tomorrow, the carry trade unwind has its own momentum (J-ICS regulation, BOJ hiking cycle, FY-end repatriation). Even if Japan stabilized, the Hormuz supply destruction follows the Hamilton lag.

**The deck should make this explicit:** the audience should understand that there are two loaded guns, not one, and they're both pointed the same direction.
