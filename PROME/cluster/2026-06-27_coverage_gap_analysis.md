Not a standalone agent.

**2. Pension LDI / DB doom-loop → DOWNGRADE to watch-only / trigger-gated.**
Real mechanism (2022 UK LDI), genuinely unowned (SHADE explicitly excludes pension DB). But: (a) the US LDI structure is materially less levered than the UK pooled-fund structure that blew up; (b) the doom-loop is conditional on a **sharp rate spike**, which is not the current regime or the live thesis path (HY-decoupling/credit, not a rate shock); (c) the synthesis itself lists "pension rebalancing" as out-of-scope "2027+ timing." → A **tail watch**, armed on a rate-spike scenario — consistent with the standing rule (deploy on a fired trigger, not calendar). Not a node to stand up now.

**Conclusion:** no new agent is warranted today. The high-value move is a **mandate extension**, not a new node.
