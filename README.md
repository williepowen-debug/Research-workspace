Research-workspace — A multi-agent financial research system built on Claude Code. ~36 specialist agents coordinate via file-based inbox/outbox over a shared git repo. A signal-intake agent (WALTER) classifies and routes external signals to a shared archive (BOARD); a carrier agent (HERMES) delivers mail between agent inboxes; an orchestrator (PROME) on Kimi-K2 handles coordination and proposal routing. Domain specialists run as independent Claude Code sessions. A RED-team agent adversarially challenges every thesis. Used daily for real positioning decisions over 8 months.
Entry points: AGENTS.md (roster and transmission chains), CLAUDE.md (system rules), PROME/STATUS.md (current system state).
