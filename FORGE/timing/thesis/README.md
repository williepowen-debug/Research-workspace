# FORGE/timing/thesis/

**What we believe will happen, and how that belief has changed.**

## Files

- `NARRATIVE.md` — **Start here.** The thesis in plain language. What we believe and why.
- `TIMELINE.md` — Phased timeline with falsifiable assumptions and position alignment.
- `PREDICTIONS.md` — Specific, falsifiable calls with tracking. Monthly review cadence.
- `CHANGELOG.md` — Decision journal. Every thesis change logged with date, trigger, old view, new view, and evidence. Read this to understand how views evolved.

## Rules

1. **Every change gets logged.** No silent edits to TIMELINE.md. Update the changelog first, then the thesis.
2. **Date and data-stamp everything.** A future Prome needs to know what we knew when we made the call.
3. **State what would make us wrong.** Every phase has a "what would change this" section. If a falsification trigger fires, log it and adjust.
4. **Separate conviction from precision.** "May-July" is a conviction window. "May 15th" would be false precision.
