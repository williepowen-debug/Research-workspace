# Research — External LLM Outputs

Raw research docs generated by external LLMs (Gemini, Kimi, Perplexity, ChatGPT, DeepSeek) from prompts in `WILL/PROMPTS.md`. Organized by topic.

## Structure
```
research/
├── fertilizer/          # Hormuz fertilizer supply chain + CF/MOS/NTR trade thesis
├── oil/                 # Hormuz oil reversal analogs, downstream impacts
├── labor/               # UCFE mechanics, claims data, DOGE
├── banking/             # Forced disclosures, 8-K patterns, CRE recognition
├── tech-deflation/      # TSMC, hedonic adjustment, Core PCE
└── README.md
```

## Naming Convention
`YYYY-MM-DD_[model]_[short_description].[ext]`

## Quality Notes
- Always cross-verify across 2+ models before trading on data
- Gemini deep research = highest detail/sourcing
- Kimi = solid, specific, honest about gaps
- Flag any hallucinated numbers in LESSONS.md
