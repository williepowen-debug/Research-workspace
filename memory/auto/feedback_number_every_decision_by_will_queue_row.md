**Will, 2026-08-29 (in-session):** *"when you give me a decision I would like it numbered. so I can simply just respond something like Will-05 = yes approved … then we could have a running list or log of decisions and ones still waiting on me."*

**Rule:** every `> ⚖️ **YOUR DECISION**` block in Will-facing chat carries a `WILL_QUEUE.md` row number (`⚖️ WQ-118 — …`), and the row is REGISTERED before the block is shown — never a decision without a row, never a row minted after the ruling. Will answers by number (`WQ-118 = approved`); PROME closes the row on the word (RECENTLY DONE = the log).

**Why:** the queue already IS the numbered decision ledger (OPEN / RECENTLY DONE, gate-nagged on due/passed). A separate "Will-NN" series would be a second numbered list beside it — the numbering-collision class root CLAUDE.md documents for "rule #6". One series, one log, one place to see what still waits on Will.

**How to apply:** draft the WQ row first (Item · Type · Needed by · Since · PROME rec · Notes), insert it, THEN write the chat block citing the number. In-session quick rulings still get a row (register → rule → RECENTLY DONE in the same touch). Other desks that surface Will decisions through PROME inherit the number PROME assigns.
