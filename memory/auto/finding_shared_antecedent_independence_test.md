The classic convergence independence test ("shared root cause?") catches the obvious case: 4 agents all reporting downstream effects of one war shock = 1 signal with 4 transmission paths, not 4 independent signals. That's the one-pass test, applied at signal-creation.

The subtler failure mode: two signals that genuinely *were* independent at creation can become non-independent later if a shared antecedent assumption flips state. Both signals quietly assume X is on track; X is generated by a third process neither signal directly observes; X breaks; both signals' load-bearing premise just died simultaneously. The "independent convergence" evaporates at integration time.

**Mechanism (validated 2026-06-06 NEXUS E-phase):**
- SIG-A: CFTC Brent positioning showing paper-long distribution at $106-111 (5/15) — looks like positioning/flow signal.
- SIG-B: HAWK reframing Iran/Hormuz to bifurcated partial-thaw scenario weights (5/22) — looks like geopolitical-scenario signal.
- Different datasets, different methods, different agents. Independence test (one-pass) passes.
- BUT both signals quietly assumed *Iran-thaw on track*. SIG-A's paper-long distribution made sense in a thaw context (specs taking profits as risk premium deflated). SIG-B's partial-thaw weighting was the thaw assumption made explicit.
- Iran SUSPENDED the MOU 6/1. Shared antecedent flipped state.
- Both signals' load-bearing premise died at the same moment. The "independent convergence pointing same direction (energy premium deflating)" collapsed into 1 root not 2.

**Rule:** before integrating N signals as "N independent roots pointing same direction":
1. Apply standard independence test at signal-creation (shared root cause?).
2. List each signal's antecedent assumptions explicitly.
3. Check freshness — has any shared antecedent changed state between signal generation and now?
4. If yes, treat as 1 root not N, even if signals look independent on their faces.

**How to apply:**
- Applies anywhere convergence-of-independent-signals is used to upgrade confidence (NEXUS convergence matrix, multi-agent thesis confirmation, multi-source verification).
- Codified as NEXUS Synthesis Discipline F (2026-06-06 CLAUDE.md update); transferable to any agent doing cross-signal synthesis (CARL multi-channel thesis tracking, PROME orchestral synthesis, BROCK multi-name aggregation).
- Especially load-bearing when signals are weeks-old at integration time — the longer the gap between signal generation and synthesis, the higher the risk a shared antecedent has shifted state silently.

**Reverse application (caught same-day 2026-06-06 orchestrator review):** the same risk applies in *reverse* when a fresh signal upgrades a convergence. NEXUS upgraded M-06 ↑5pp on "war path re-armed" — but that rests on Iran re-escalation holding past the next gate (6/8 Trump/Rubio response). Same shared-antecedent risk in the bullish direction. Conditional flag added to M-06 row.
