After a run of "insurance-nexus digs came back not-actionable," WALTER collapsed to the wrong metric ("no discrete trade → null result"). **Will rebuked this directly (2026-07-21).**

**Why:** the fleet is an intelligence-brief output more than a P&L-attribution output. Grading only by discrete trades systematically undervalues most of what the research actually produces, and biases agents toward forcing trade calls out of work whose value is structural.

**How to apply — six non-trade value tracks, all worth carrying and reporting as real results:**
1. **Mental-model completeness** on a structurally-opaque domain — recognize an event in real time as the mechanism already tracked.
2. **Calibrated base rate on a class of narrative** — N converging "real, not fired" digs is a routing-tuning output (down-weight the whole source class).
3. **Regime-timing constraint on adjacent theses** — "slow, not imminent" frees tail-risk budget elsewhere.
4. **Positioning implications without a discrete trade** — long-vol bias, IG-underweight, duration, cohort composition.
5. **Pre-mortem hardening** — when the event lands: "surprise → recognized event class → known response," which is convex value on the day.
6. **Narrative-recognition front-run** — when mainstream press catches up to a fleet-held thesis, the catch-up itself is tradeable via broad expressions (e.g., CNN mainstreaming the median-short-interest datum, 7/23).

When summarizing a research wave to Will, report which tracks it advanced — not only whether a trade emerged.
