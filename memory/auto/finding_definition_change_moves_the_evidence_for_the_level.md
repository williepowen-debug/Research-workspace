**A spec pass that changes a DEFINITION and re-affirms a LEVEL in the same packet must rule the definition FIRST — because the definition change moves the evidence base the level is being re-affirmed against.** Ruling them together records a standing that the same ruling session dissolved.

**The instance (HOMER, 2026-08-22, caught by PROME before it reached Will).** I filed a threshold-anchoring proposal with three asks I listed as independent: (1) re-affirm three numbers, (2) rule whether undrawn shelf *capacity* counts as a dilution event, (3) record each number's evidentiary standing. I had written the dilution threshold's standing as **"fragile at n=2."** But ask 2 was the question of whether the *second* observation existed — ruling capacity out (which I recommended, and which Will ruled) **dropped that class to n=1**. ⇒ **Ask 1 asked for re-affirmation of a number that ask 2 simultaneously weakened, and ask 3 would have frozen a pre-ruling standing into the record.**

**Why it is not obvious in the moment:** the definition question *feels* like housekeeping next to the numbers — it has no digits in it. **The scope clause is what decides which events count, so it is upstream of every count, every rate, and every "n=" in the document.** I had even argued *for* the ruling that cut my own sample from two to one; **I still failed to propagate it into the standing I was proposing in the same file.**

**Rule.** When one artifact carries both a definition/scope change and a level decision:
- **Order the asks so the definition is ruled first**, and say in the packet that the later asks depend on it.
- **Write any count, rate, or evidentiary standing only AFTER the definition is settled** — never in the same draft that proposes changing it.
- **State the conditional explicitly**: *"if capacity is ruled out, this standing reads X, not Y."* That way a ruler who takes the recommendation cannot accidentally ratify the stale half.

**Tell:** a packet whose asks are numbered as a list, where one of them changes what counts as an observation for another. **Test: for each ask, ask "does answering this change any number, count, or n= elsewhere in this document?"** If yes, they are sequential, not parallel.

**Generalizes past thresholds.** Any pass that re-scopes an instrument while also grading it: re-defining a metric's basis then reporting its level; narrowing a population then quoting its rate; changing what qualifies as an event then citing an event count. **The definition is always upstream of the measurement, and a document that edits both at once is measuring against a basis it is simultaneously proposing to change.**
