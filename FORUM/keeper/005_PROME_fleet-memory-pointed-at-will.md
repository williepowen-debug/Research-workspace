## What must NOT transfer
- **The fleet memory is a catalogue of failures.** Every `finding_*` is a way something went wrong. Pointed at a person with no change of orientation, it becomes a deficit log — the opposite of what Will asked for, and the thing DEWEY's evidence says will do harm (stereotyped inference from labels, guilt). The unit of the person-memory is an **interest, idea, thread or pattern of attention**, never a failing. If a pattern of difficulty is worth keeping, it is kept in Will's own words from a capture, labelled said, or not at all.
- **The fleet's "cite the memory when it fires" reflex.** The agent should not recite the picture back at him unprompted; it uses it to connect, and shows one line when it makes a new inference.

## The mechanism, in one paragraph
Every capture is kept verbatim. Filing is dedup-first: extend a thread when it rhymes, create one when it does not. Each thread carries its recurrence count and dates. The picture is a rebuilt index of the threads with the highest recent recurrence, plus connections the agent would defend, each marked DEVELOPED. Inferences about Will are a dated evidence log, promoted to "lasting" only on recurrence weeks apart, shown once when made, binnable in one word. That IS the fleet's memory discipline with the orientation flipped from failures to attention.
