# TIC Data Analysis Framework
*Reusable reference for monthly TIC releases*

## What TIC Shows
Treasury International Capital (TIC) reports foreign holdings of US Treasuries. Released monthly with ~6-week lag.

## Key Focal Points Each Release

### 1. Belgium (Euroclear Proxy) — $500B Watch
- Belgium = tell for European custodial selling via Euroclear
- Baseline ~$300B (2023), reached $481B (Nov 2025)
- If declining from ~$500B toward $450-480B = European official sector in structural exit
- Cross-ref with BIS Table B4 to distinguish custody migration vs actual exit

### 2. Japan
- Largest holder (~$1.1T). Life insurers selling $10-15B/month
- Hedge ratios down 50%→30%
- If >$20B net sell in single month = MARCO/SAM signal

### 3. China
- ~$750-780B range (official TIC only; true exposure ~$2.5-2.8T via Belgium/Euroclear)
- Any drop below $750B = meaningful escalation of disengagement
- Peak $1.32T (Nov 2013) → steady decline

### 4. Gulf States (Saudi, UAE, Qatar, Kuwait)
- Below fiscal breakeven (~$80/bbl) even before war premium
- If selling in calm baseline months = confirms structural fiscal position, not just war disruption

### 5. Total Foreign Holdings
- Aggregate decline >$50B MoM = demand hole thesis gaining hard data
- Prior months: $30-55B range

## Interpretation Frame
- TIC = snapshot of past month. Market interprets forward.
- Contrast between TIC (lagged calm data) and current auction demand = the signal
- Weak TIC + weak auction BTC = foreign demand **secular** deterioration
- Strong TIC + weak auction = war-specific disruption (more recoverable)

## Gulf Chaos Overlay
When Gulf conflict active: current selling rate far exceeds TIC snapshot. If TIC (calm baseline) shows $40-60B selling, current rate (post-conflict) is running $70-100B/month. Combined Belgium + China flow at -$100B/qtr = RED threshold.
