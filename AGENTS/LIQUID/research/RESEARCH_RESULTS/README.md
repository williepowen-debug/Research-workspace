# LIQUID Research Results

This folder holds outputs from deep research LLM sessions.

## Naming Convention

`[##]_[TOPIC]_RESULTS.md`

Examples:
- `01_RRP_DEPLETION_RESULTS.md`
- `02_SOFR_STRESS_RESULTS.md`

## Processing Workflow

1. Research LLM completes prompt
2. Save output here with appropriate name
3. Start fresh LIQUID session
4. LIQUID processes results into:
   - `workbook/VX.tsv` — Vector values
   - `workbook/ML.tsv` — Key observations
   - `workbook/FL.tsv` — Future catalysts identified
5. Update `../RESEARCH_INDEX.md` status to COMPLETE
6. Update `../../RESEARCH_STATUS.md`
