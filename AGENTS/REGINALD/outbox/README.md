# REGINALD outbox — sender-side copies only

Since 2026-10-22 (charter step 12, DAEDALUS D:L793 item 7), deliveries go to the recipient's inbox: `PROME/inbox/` for PROME, `AGENTS/<NAME>/inbox/` for desks. This folder holds optional sender copies and is never the only delivery. A file here does not show that the recipient read it. Packets older than 60 days retire to `archive/` (first batch 2026-10-22 → `archive/RETIREMENT_2026-10-22.md`).
