# Brotli CVE-2026-111497 now has Bun and Envoy primary advisories; update the existing incident rather than counting another flaw

This extends SIG-W-20261023-041 / **CYB-INC-027**, whose source was the Node.js advisory. Same CVE, broader documented dependency reach.

- [Bun GHSA-663w-cv8g-jj2p, October23](https://github.com/oven-sh/bun/security/advisories/GHSA-663w-cv8g-jj2p), read in full: affected >=1.0.21,<1.4.4; fixed1.4.4. Its fetch API decodes Brotli responses by default, so a malicious server can supply decoder input. Compiled executables need rebuilding. Bun rates it High and has **not tested an attack against Bun**; do not turn risk into successful exploitation.
- [Envoy GHSA-3wvj-j6qm-62mr, October23](https://github.com/envoyproxy/envoy/security/advisories/GHSA-3wvj-j6qm-62mr), claim/versions/impact/credits read: requires the **Brotli decompressor configured**; fixed1.40.0/1.39.3/1.38.6/1.37.8/1.36.12; Critical9.2. Credits OpenAI Security Research. Version1.36 is not made supported by a patch listing.
- Aikido's [October23 article, updated October25](https://www.aikido.dev/blog/python-packages-vulnerable-node2shell-brotli-cve-2026-111497), relevant body read, also identifies Python Brotli/brotlicffi. Python advisory not independently read. Its later update lists patches, qualifying the bookmarked claim that fixes were not available. A generic HTTP library or every HTTP server is not automatically vulnerable.

Item9's Cloudflare-CEO weekly-vulnerability quotation is **unverified contextual rhetoric**, not independent corroboration, exploit telemetry or a separate incident. No newly checked CISA KEV state is asserted here.

**CYPHER ACTION:** extend CYB-INC-027 reach and dated patch states; verify Python/upstream advisory and exploit status at the next owner read. PROME receives a dependency-review lead; no fleet patch/deployment executed. WALTER review October26.
