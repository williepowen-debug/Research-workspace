| Item | Verdict | Key facts (date, source) |
|---|---|---|
| PHP2Shell exploitation | **Attempts confirmed; no successful compromise confirmed** | Cloudflare CEO: attempts "from thousands to millions within hours" (his X post, via Reuters). **CISA KEV catalog pulled 10/22 17:56Z (v2026.10.21): neither CVE listed**; CISA has not observed exploitation; watchTowr reports "in the wild" from decoy servers. CrowdStrike's blog: compromise leaves "virtually no digital footprint" (lab finding), so "none confirmed" is weaker than it sounds |
| PHP exposure counts | Counts conflict, carry all | VulnCheck 2,608,039 internet-facing PHP hosts (about 1.1M on old versions, helper's sum of two VulnCheck groups); Modat 4.38M services; Censys about 1.57M unpatched; Palo Alto 22.6M "instances" |
| Bank shutdowns | **Japan only** | MUFG, Mizuho, Daiwa, Nomura, Shizuoka, Aomori Michinoku, Yamanashi Chuo, San-in Godo (precautionary). **No US/European bank, credit union or core-banking vendor (Fiserv, Jack Henry, FIS, Q2, Alkami, NCR Voyix) found.** Outside Japan: government sites, Orange, Dutch hospitals, BBC |
| eMudhra (Indian certificate authority) | **Mostly confirmed** | Eight intermediate keys had tiny private values, all below 256, one equal to 4 (Mozilla bug 2083449; found 10/17). Mozilla and Chrome blocked them 10/17; Apple 10/19 and Microsoft 10/20 per secondaries. Mozilla pulled emSign ECC Root G3 about 10/20; Chrome removes it 10/27. **"60M certificates can't be trusted" is FALSE:** 60M is lifetime issuance; eMudhra says the eight keys issued none and Google finds none in CT logs; about 30,000 certificates under G3 need migration. Tailscale bulletin TS-2026-013: update to 1.104.2+ |
| "pip install is compromised" | **FALSE; upgrade advice CONFIRMED** | A trust-list issue, not a pip or PyPI breach. Python.org (10/20) and Astral/uv (10/20) advise upgrades. Risk needs an on-path attacker; **no attack reported**. Exposure is non-browser software with stale certificate lists (trading bots, API clients) |
| LiteLLM (AI developer tool) | **Confirmed** | Malicious 1.107.0 on PyPI 10/21 11:39–13:23 UTC; Docker tags bad until about 14:20 UTC. "23M downloads a week" is total package volume, not this release's exposure |

| Linux KSMBD (kernel file-sharing server) | **Confirmed, narrow exposure** | Two CVSS 9.0 flaws (one unauthenticated) disclosed before a mainline fix; KSMBD appears off by default upstream and absent from RHEL; other distro defaults UNVERIFIED |

**WALTER's read (mechanism, not a finding):** this is a pile-up of separate incidents with two broad holes (PHP2Shell, eMudhra) and many supply-chain poisonings, accelerated by AI-assisted exploit discovery (Wiz: "AI inflection point", 019). The market-relevant tail is a confirmed mass compromise through PHP2Shell that was invisible for weeks; nothing confirms that yet.

**Do not relay:** "1/3 of the internet is down," "60 million certificates are untrusted," "pip is compromised," "banks worldwide went offline" (Japan only).

**SHADE ACTION:** cyber-insurance aggregation watch; no insurer or rating-agency statement yet. **REGINALD ACTION:** updates 019; no US bank or core-vendor impact found.
