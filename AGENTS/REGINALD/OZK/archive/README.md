## File Instructions

**What belongs here:**
- Completed audit reports (structure, data quality, gap analysis)
- Resolved planning documents (restructure plans that were executed)
- Anything that was useful once but is now done

**What does NOT belong here:**
- Active analysis → `../research/`
- Current data → `../workbook/`
- Anything you might need to reference during live work

**Rule:** Move here, don't delete. If something turns out to be relevant again, move it back.
