## Methodology Notes

- **RCONJ454** = "Loans to nondepository financial institutions" (domestic offices)
- **RCFDJ454** = Same, consolidated (domestic + foreign offices)
- **RCON PV05-PV09** = Subcategory breakdown (mortgage credit, business credit, PE funds, consumer credit, other)
- For system totals: use RCFD where available (80 banks), RCON for remaining 4,314
- Units = thousands ($). Verified: RCON2122 system sum = $12.87T domestic, matches FDIC QBP.
- Zero CONF (confidential) values in NDFI columns.
- Data file: `FFIEC CDR Call Schedule RCCI 12312025` (tab-delimited, 4,396 lines incl. header + description row)
- FDIC QBP verification: `qbp-time-series-spreadsheet-fourth-quarter-2025.xlsx`, Balance Sheet tab, row 29
