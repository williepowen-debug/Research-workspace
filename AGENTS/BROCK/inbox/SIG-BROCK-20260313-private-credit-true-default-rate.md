**Source:** Financial Times chart, S&P Global Ratings (Credit Estimates database)

**Raw signal:**
- Chart: 12-month default rates 2018-2026, three series:

  - Private credit narrow definition (solid red): currently ~1.5%

- Dotted red line has been consistently 2-3x the solid red line since 2023
- Private credit "including selective defaults" is already AT or ABOVE public spec-grade levels
