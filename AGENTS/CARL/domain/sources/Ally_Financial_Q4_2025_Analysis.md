## Executive Summary

Ally Financial deliberately shifted away from subprime toward S-tier (highest credit quality) in 2025. This report provides the "prime lender baseline" against which subprime stress (OTTO vectors) should be compared.

**Key Takeaway:** The K-shape is real and widening. Ally's metrics are improving while subprime sector hits record stress.
