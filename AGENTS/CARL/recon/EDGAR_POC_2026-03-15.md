## TL;DR: YES, fully automatable.

EDGAR's search API returns JSON. The actual 10-D EX-99.1 exhibit is a structured HTML monthly report with clearly labeled line items. `curl` + simple HTML parsing extracts the data cleanly. No manual download required.

## What I Tried

### Step 1: EDGAR Full-Text Search API
**URL:** `https://efts.sec.gov/LATEST/search-index?q=%22santander+drive+auto%22&dateRange=custom&startdt=2026-01-01&enddt=2026-03-15&forms=10-D,ABS-15G`

**Result: ✅ WORKED**
- Returns clean JSON (Elasticsearch format)
- 108 hits for Santander Drive Auto in the date range
- Multiple trusts file simultaneously (2022-2 through 2025-4)
- Most recent batch: **filed 2026-02-17**, period ending **2026-01-31**
- Also found ABS-15G filed **2026-02-10** (period ending 2025-12-31)

Note: `web_fetch` works on `efts.sec.gov` without auth issues.

### Step 2: EDGAR Company Browser (www.sec.gov)
**URL:** `https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&company=santander+drive+auto&type=10-D...`

**Result: ❌ BLOCKED (403)**
- SEC.gov blocks requests without proper `User-Agent` header
- Fix: Add `User-Agent: YourCompany/1.0 email@domain.com` header
- `curl -A "CARL-Research/1.0 carl@example.com"` resolves this

### Step 3: Fetch Actual Filing Content
Using curl with User-Agent on the direct archive URL:
`https://www.sec.gov/Archives/edgar/data/{CIK}/{accession}/{filename}`

**Result: ✅ WORKED**

## Automation Assessment: FULLY AUTOMATABLE

### Why it works well
1. **EDGAR search API** (`efts.sec.gov`) returns JSON — no scraping, no auth
2. **Filing archive** (`www.sec.gov/Archives/edgar/data/`) is directly accessible with proper User-Agent
3. **EX-99.1 format is structured** — line items are numbered `{79}` through `{107}`, consistent across all trusts and months
4. **All trusts file simultaneously** — one search query returns all vintages for a given period

### Automation blueprint
```python
# 1. Poll EDGAR search for new 10-D filings
search_url = "https://efts.sec.gov/LATEST/search-index?q=%22santander+drive+auto%22&forms=10-D&dateRange=custom&startdt={start}&enddt={end}"

# 2. For each hit, construct archive URL:
#    https://www.sec.gov/Archives/edgar/data/{CIK}/{adsh_nodash}/{filename}

# 3. Fetch with User-Agent header (required!)

# 4. Parse HTML — extract line items by searching for {79} through {107}
#    60+ day delinquency = line {85}
#    CNL = line {107}
#    Repossessions = lines {88}-{93}

# 5. Store time series per trust vintage
```

### Caveats
- **User-Agent required** — plain requests get 403'd. Must declare company info.
- **Rate limits** — SEC allows 10 req/sec. Comfortable for 20-21 trusts/month.
- **Format consistency** — spot-checked one trust. Should verify across 2-3 vintages before deploying.
- **ABS-15G** is a different format (repurchase demand disclosures) — less useful for performance tracking.
