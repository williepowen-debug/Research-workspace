## S — SYNTHESIS

### Key Mental Model

**Core Thesis:** The gig economy has become a trap rather than an opportunity. It functions as both symptom (workers flee to gig when traditional employment fails) and cause (oversupply compresses earnings, accelerating stress). Gig worker distress is a LEADING indicator—these workers feel economic compression before it appears in official statistics.

**What Matters Most:** Earnings per worker relative to hours worked. If workers must work more hours to earn the same income, the system is compressing. This is the core saturation signal.

**Biggest Uncertainty:** We don't yet know the current baseline. Are we in Phase 2 (Saturation) or already transitioning to Phase 3 (Compression)? Q4 earnings data will help locate us.
