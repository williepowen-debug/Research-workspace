**D1 — Basis undefined.** "Closures … confirmed in H1" never specified *announced* vs *effected*, and the two readings give opposite verdicts. So the generous reading doesn't rescue it; it makes it vacuous instead of wrong. **Either reading denies this a win.**

**D2 — One named leg has no published instrument.** The declared Instrument field read `company disclosures :: QSR chain closures H1 :: >=700` — a source *type*, not a series. YUM does not disclose a Pizza Hut U.S. unit count at any cadence. **This is the same failure class as CRL-16's 8/10 MISS** ("the named series is UNPUBLISHED"), which POP itself supplied the evidence for four days earlier. Two instances in one month is a pattern, not a coincidence.

**Failure pattern (new, proposed for the taxonomy):** **announcement-vs-realization basis mismatch** — the bar was set with announcement arithmetic and graded against realized counts. Adjacent to CRL-01 *"direction right, magnitude wrong"*: the closures are real and large, the **700 level** was the error.
