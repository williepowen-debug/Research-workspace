## Section 3 — Architectural recommendations

These respond to the issues above and to the external-LLM-proposed fixes.

### 3.1 Add `Delegated_To` column to SCHEMA.tsv (highest leverage)

44 rows currently overload `Status` with delegation info. Proposed schema addition:

```
Delegated_To  String  Sub-agent name from {HOMER,LABOR,GIG,STUE,PHAN,POLLY,POP,DOC} or empty   No   ""   Sub-agent that owns this entry's domain. Empty if CARL-direct.
```

Migration: for each of the 44 rows, set `Status = SUPERSEDED` (or CONFIRMED if still load-bearing) and `Delegated_To = HOMER`. The `Notes` column already references the handoff in most cases.

### 3.2 Add `Last_Refreshed` column

Distinct from `Date` (original logging). Cheap path to staleness analytics across the whole TSV. Alt: derive from `git log` per row, but that's expensive — explicit field is simpler.

### 3.3 Extend SCHEMA.tsv to ALL workbook TSVs
