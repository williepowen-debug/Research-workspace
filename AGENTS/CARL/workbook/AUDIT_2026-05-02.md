## Section 3 — Architectural recommendations

These respond to the issues above and to the external-LLM-proposed fixes.

### 3.1 Add `Delegated_To` column to SCHEMA.tsv (highest leverage)

44 rows currently overload `Status` with delegation info. Proposed schema addition:

```
Delegated_To  String  Sub-agent name from {HOMER,LABOR,GIG,STUE,PHAN,POLLY,POP,DOC} or empty   No   ""   Sub-agent that owns this entry's domain. Empty if CARL-direct.
```

Migration: for each of the 44 rows, set `Status = SUPERSEDED` (or CONFIRMED if still load-bearing) and `Delegated_To = HOMER`. The `Notes` column already references the handoff in most cases.

### 3.2 Add `Last_Refreshed` column

Distinct from `Date` (original logging). Cheap path to staleness analytics across the whole TSV. Alt: derive from `git log` per row, but that's expensive — explicit field is simpler.

### 3.3 Extend SCHEMA.tsv to ALL workbook TSVs

Currently SCHEMA.tsv defines only KB.tsv columns. The 5 drift-heavy TSVs (BNPL_STRESS, STATE_DIFFUSION, TRENDS, ABS_BASELINE, ML if kept) need formal column definitions to be auditable. This is a one-shot task: write the schema, fix existing rows to match.

Order of priority (by current drift severity):
1. BNPL_STRESS (93% drift)
2. TRENDS (90% drift) — but already flagged for retire-or-refresh decision
3. STATE_DIFFUSION (77% drift)
4. ABS_BASELINE (51% drift)
5. VX, FLOW (clean — just need schema docs)

### 3.4 Build `validate_workbook.py`

The script `/tmp/audit_kb.py` used for this report is the prototype. Promote to a permanent tool at `workbook/tools/validate.py`:

- Reads SCHEMA.tsv to discover allowed values dynamically (no hardcoded enums).
- Runs all 8 check categories from §1 above.
- Exits non-zero on any violation (CI-style).
- Adds: column-count mismatch detection (which would have caught the column-bleed bug at write time, not 15 days later in audit).
- Suggested invocation: top of every CARL spawn protocol (step 0.5, between `git pull` and reading SCRATCH).

### 3.5 Stale_By hygiene rule

When `Status` transitions to SUPERSEDED or CORRECTED, blank the `Stale_By` field (or set it to date-of-supersession). Currently 1 known violation (KB-029); script can enforce going forward.

### 3.6 Workbook root `INDEX.md`

One-screen file inventory + schema reference + last-update-line per file. Not load-bearing for CARL boot (boot doesn't read top-down), but useful for human + external-LLM orientation.

### 3.7 Methodology preservation

External LLM flagged: v2.5 recalibration (58/60 → 53/70 with explicit calibration vs evidence-change attribution) is a methodology pattern worth codifying. Currently in `thesis/CHANGELOG.md` only. Suggested: extract into `thesis/METHODOLOGY.md` or as a CLAUDE.md section. Backlog item.
