# Cyber, Friday 10/23 evening: "Node2Shell" is a new Node.js remote-code-execution flaw (rated High, fixed 10/21, not on CISA's exploited list); Google says PHP2Shell exploitation is not yet validated in the wild but "may have already begun in a limited fashion"; two breach claims (EMARKETER, Coop Italia) are unverified; DEWEY's Korea read: 16 firms breached through weak authentication, AI role unproven

| Item | What is established | Limit |
|---|---|---|
| **Node2Shell, CVE-2026-111497** | Node.js advisory 10/21: Brotli decoder out-of-bounds write permits remote code execution, rated **High**; affects 22.x, 24.x, 26.x; fixed in **v22.23.4, v24.22.1, v26.12.1**; no workaround. Not in CISA KEV (feed 10/23 19:30Z); THN: no exploitation in the wild as of 10/22 | "Pre-auth" is Imperva's/THN's word, not the advisory's: the app must decompress attacker Brotli (THN: express.json() does on Express 5 / body-parser 2; a bare Node server does not). Imperva's proof "did not succeed on every attempt". No CVSS published |
| **PHP2Shell (CVE-2026-109618/-109619), Google update** | Hultquist (The Record 10/23): exploitation in the wild not validated, but "exploitation may have already begun in a limited fashion and the threat is viable and very serious". Patched: PHP 8.5.12, 8.4.27, 8.3.36, 8.2.35; CVSS 9.2. Neither CVE in KEV | VirusTotal 10/21: ~5.1M IPs run PHP, ~758K on end-of-life branches, ~80% hide their version; footprint, "not confirmed vulnerable hosts" |
| **EMARKETER (Axel Springer)** | FulcrumSec claims 15.8 TB, 15.3M subscriber profiles, via exposed AWS keys and GitHub tokens | CLAIM-ONLY: no company statement or outlet coverage found (hours old) |
| **Coop Italia** | Qilin leak-site listing (DailyDarkWeb) | CLAIM-ONLY: no statement or coverage found |
| **Korea, 16 firms (DEWEY)** | FSC 10/14 primary: 16 firms, ~100,000 records (names, resident numbers; no passwords or cards); entry through missing or bypassable authentication.
