# ISHM — US manufacturing and industrial cycle

The desk asks whether the factory upturn reflects durable end-demand or tariff timing, concentrated capex and inventory rebuilding. This directory is rooted at `AGENTS/ISHM/`; commands below run from the repository root.

```text
AGENTS/ISHM/
├── CLAUDE.md, FIRST_SESSION.md       # desk charter and completed startup receipt
├── STATUS.md, NEXUS_BRIEF.md         # current judgment and cross-desk synthesis
├── DATA_ROUTES.md, PERIMETER.tsv     # measured access and approved company scope
├── RELEASE_PREP_2026-10-27.md        # durables / Richmond reading contract
├── data/                            # frozen historical panels and source metadata
├── companies/                       # eight company files, fixed earnings checklist
├── workbook/                        # print, claim, score, mechanism and forecast ledgers
├── docket/CATALYSTS.tsv             # print-driven calendar
├── research/                        # dated analyses, captured sources and reproducers
├── inbox/, outbox/, board_log.tsv   # coordination and intake dispositions
└── boot.py, scripts/                # boot instrument and drills
```

Start with [STATUS](STATUS.md), then the [release plan](RELEASE_PREP_2026-10-27.md). Figures and vintages live in [PRINTS](workbook/PRINTS.tsv); [KB](workbook/KB.tsv) holds atomic claims. [EXIT_PROTOCOL](workbook/EXIT_PROTOCOL.md) defines falsification tests. Empty predictions and the frozen no-book trade file are intentional.

The October 26 build added [historical panels](data/README.md), [all eight company files](companies/README.md), and [a reproducible evidence report](research/2026-10-26_buildout/REPORT.md). Frozen histories are current-vintage observations, not reconstructed first-published histories. Refresh them by preserving a new dated source snapshot, never by silently replacing the old vintage.

Remaining evidence gaps are listed with owners and next dates in STATUS: long ISM/S&P component histories, weekly AAR calibration, broader independent freight/credit episodes, real imported-hardware attribution and an aligned equity-reaction panel. October 27 releases and the Q3 equipment/September imports needed for a complete J1 test have not yet published at this evidence cutoff.
