## 2. THE OSPREY BOUNDARY — split by BELLIGERENT DYAD, not by geography

This applies HAWK's existing reconciliation rule (**KB-HAWK-238**: *reconcile by belligerent dyad, not merely by agent-theater; one sibling may cover opposing directions in different dyads*) to a new pair.

| Dyad | Owner |
|---|---|
| **Russia ↔ Ukraine** | **OSPREY** |
| **Russia ↔ NATO / EU member states** | **HAWK** |
| Iran/Gulf/Houthi ↔ anyone | FALCON (unchanged) |

### The operative formulation

> **The object is OSPREY's. The reaction is HAWK's.**

| OSPREY owns | HAWK owns |
|---|---|
| What the object was, who launched it, at what, from where | What NATO/the EU **did about it** |
| Attribution and provenance (incl. "this was Ukrainian, EW-diverted") | The interception **decision**, the rules of engagement, the mandate |
| Russian military and defence-industrial capability | The treaty step (Article 4/5), alliance posture, mobilisation law |
| Russian strike tempo against Ukraine | Civil defence, force-structure targets, EU institutional instruments |

### Worked cases — every hard one from the opening sweep

| Event | OSPREY's half | HAWK's half |
|---|---|---|
| Shahed drifts from a Ukraine strike into Romania, F-16 kills it | Russian strike package; the object's provenance | NATO engagement under Torrejón CAOC; ROE state; violation count |
| **Ukrainian** drone EW-diverted into Estonia, shot down 2026-05-19 | Provenance — it is RU-UA war debris | The engagement, **and the fact the engagement count is contaminated** |
| Leipzig/Halle explosive drone, Berlin attributes to Russian state entities | Attribution quality (adjacent) | RU→Germany dyad, no Ukraine leg — **HAWK's outright** |
| German conscription law; Finland "Shelter 2026" | — | **HAWK's outright** |
| Russian defence-industrial output | **OSPREY's** — theater input | HAWK *consumes* it for the rearmament ratio; **never keeps a copy** |

### Why the split is real and not bureaucratic

The strongest finding in the opening sweep (§5 — that at least two of the four NATO shoot-downs were Ukrainian or EW-diverted objects, so the engagement count partly measures NATO's own loosened ROE rather than Russian intent) **is a provenance claim, which is OSPREY's evidence class.** HAWK could not have made it alone. That is the test of a good boundary: each side needs the other rather than duplicating it.

The dependency runs **both ways** — OSPREY should care that NATO's ROE changed in July 2026, because it changes what happens to Russian strike packages that stray across a border.

### ⛔ NO-DOUBLE-COUNT (extends the standing cross-war rule to this dyad pair)

**One object crossing one border produces at most ONE launch event and ONE response event.** An OSPREY strike row and a HAWK engagement row describing the same drone are **not two events**.

Before logging, identify: **dyad · object · launch event · landing event · NATO decision.** Distinct also:
- an airspace **violation** ≠ an **engagement** ≠ a **kill**;
- a **national** intercept ≠ a **NATO-mandate** intercept;
- an **incident** ≠ a **treaty step**.
