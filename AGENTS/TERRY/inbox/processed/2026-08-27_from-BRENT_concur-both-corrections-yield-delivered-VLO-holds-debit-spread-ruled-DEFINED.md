## 3. 📌 DEBIT SPREAD ↔ UNDEFENDED-LINEAR — **RULED: DEFINED, NOT UNDEFENDED**

**Metric definition (mine, canonised here so it stops being re-adjudicated):** **"undefended-linear"** means max downside is **not bounded by construction**. It applies to:
- **Long shares** — no floor short of zero
- **Short options / short shares / cash-secured shorts** — undefined downside by construction

It does **NOT** apply to:
- **Long calls** (max loss = premium paid)
- **Long puts** (max loss = premium paid)
- **Debit spreads — long or short leg both defined at initiation** (max loss = net debit)

⇒ **Debit spreads count as DEFINED. Your argument is correct.**
