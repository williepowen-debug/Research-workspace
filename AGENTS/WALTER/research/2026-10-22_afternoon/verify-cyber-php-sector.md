## Claim 3: Linux KSMBD

| # | Claim | Verdict | Evidence |
|---|---|---|---|
| 3a | Two CVSS 9.0 RCE flaws disclosed on public list before fixes | CONFIRMED (with nuance) | The Hacker News 10/22 (https://thehackernews.com/2026/10/two-cvss-90-linux-ksmbd-rce-flaws.html) and Phoronix (https://www.phoronix.com/news/LKML-New-Trend-Vulnerabilities): ZDI-CAN-33774 (protocol-dispatch race; SMB1 data handled by SMB2 handler; port 445) and ZDI-CAN-33549 (SMB Direct integer underflow; needs RDMA-capable interface, negotiated SMB Direct, writable share). ZDI reports were apparently sent to public LKML instead of the private security list; Greg Kroah-Hartman replied asking about the submission. No CVE IDs yet (assigned after stable fix). Score 9.0 is ZDI's, not NVD. |
| 3b | One unauthenticated | CONFIRMED | THN: 33774 requires no auth; 33549 auth "not stated." |
| 3c | No mainline fix | CONFIRMED as of THN's Thursday 10/22 reference | THN: neither had a named fix in mainline or linux-next. Phoronix: patches only in testing/-next for 33549. Other outlets report a fix by SMB Direct maintainer Stefan Metzmacher aimed at next cycle: unconfirmed. Re-check before relying. |
| 3d | Enabled by default on major distros? | UNVERIFIED, evidence points to NO | Upstream Kconfig CONFIG_SMB_SERVER is experimental/off by default (kernel patch note via search summary). Red Hat: ksmbd not shipped, CONFIG_SMB_SERVER not set (https://access.redhat.com/solutions/6991749; THN repeats RHEL has none). One user reported ksmbd module absent on Ubuntu 22.04 5.15. I could NOT find authoritative Ubuntu/Debian/SUSE/Fedora default configs. Even where built as a module, it needs ksmbd-tools plus the user configuring and starting a share to listen on 445. Check any host: `grep SMB_SERVER /boot/config-$(uname -r)`, `lsmod | grep ksmbd`, `systemctl status ksmbd`. |
| 3e | Realistic exposure | LOW broad / HIGH narrow (my assessment, not sourced) | Exposure limited to hosts that deliberately run ksmbd (NAS, embedded, OpenWrt/Armbian-type, performance SMB servers) with 445 reachable. No exposure estimate published by any source I read. Not comparable in breadth to PHP2Shell. |
