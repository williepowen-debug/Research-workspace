**Run:** 2026-10-01 ~15:00–15:30Z, WALTER test subagent. Read-only to `~/Research-Intake`; nothing committed, no file touched except this one.

## Method

- **Instrument:** `AGENTS/WALTER/tools/watch_for_harness.py` → the lane's REAL matcher `match_watch_for()` (`~/Research-Intake/scripts/newsweep_config.py` L961), loaded in memory. Matcher rules that drive most results below: every token **>3 chars** (minus `above/below/from/with/that/this/than/into`) must appear as a **case-insensitive SUBSTRING** of the headline, in any order; tokens of **≤3 chars are DROPPED** (`oil`, `cut`, `low`, `Sea`, `war`, `ban`, `5`, `2`); ALL-CAPS 2–5-char tokens (`VVIX`, `MOVE`, `CPC`, `COR1M`) are REQUIRED entities matched case-sensitively on word boundaries.
- **Lane corpus:** 10,405 unique headlines over 71 lane days, **2026-06-29 → 2026-09-30**.
- **Live corpus:** Google-News RSS, `when:30d` (≈ 2026-09-01 → 2026-10-01), on-topic subject queries per desk (listed per section). Counts are unique headlines after dedup across that desk's queries.
- **Positive controls:** synthetic plausible real headlines per trigger, to test RECALL.
- **Classification (mine, per hit):** **TRUE** = the headline reports an event of the kind the phrase is keyed to. **FALSE** = it does not (wrong subject, talk/forecast/explainer where the trigger is a realized event, wrong place, memorial/old event). **REVERSAL** = right object, OPPOSITE state change (e.g. a terminal *resuming* when the phrase is keyed to a halt) — reported separately because whether the owner wants the reverse event paged is the owner's call, not a matcher fact.
- **Verdicts:** ⛔ REJECTED = >0 FALSE hits (R3). ✅ PASS = 0 FALSE. ⚠️ OWNER-CONFIRM = 0 FALSE but REVERSAL hits present — PASS only if the owner wants reversal pages; otherwise treat as REJECTED. **A 0/0 result where the live sample contained no event of the kind is UNINFORMATIVE on recall** and is marked so; recall then rests on the synthetic control alone.
- Alternatives shown in the notes were run on the same lane + live corpora; they are suggestions for the owner, not landed terms.
