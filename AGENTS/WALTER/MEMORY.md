## Findings

- [2026-05-05] **"verified-as-of" stamp + re-verify trigger pattern** (`anchors/IRAN_WAR.md`) — load-bearing macro state goes in a single-purpose anchor file with an explicit "verified-as-of {date}" + re-verify trigger; beats embedding in STATUS where it staleness-rots invisibly. A 2nd anchor (Fed-framework / BOJ / OPEC+) would canonize the pattern.
- [2026-05-05] **Regenerate at closeout, don't snapshot-and-let-go-stale.** Dropped the embedded NETWORK AWARENESS table (it duplicated REGISTRY and rotted); regenerate it each closeout. Applies to any state whose canonical source lives elsewhere.
- [2026-05-05] **Cluster is a discovery axis, NOT a routing axis.** Domain (FORMAT_SPEC owns) = recipient-routing; cluster (CLUSTER_TAXONOMY owns) = thematic. One signal → one domain (routing) + one primary cluster (discovery); cross-cluster gets one primary (substance > mechanism > action-recipient) + a secondary tag, never multi-placement.
- [2026-04-11] **Trust disk over memory; stale-agent flagging is a high-leverage boot output.** `ls`/grep before believing a handoff doc (`/COP.md` existed since Apr 7 while NEXT_SESSION denied it). Surface any agent with Updated >5d explicitly.
- [2026-05-11] **PROME-direct REQs need PROME's INBOX, not WALTER's outbox** (a 5/8 outbox REQ sat 2d unread). Once Will-authorized, migrate to `AGENTS/PROME/inbox/SIG-WALTER-PROME-*`. (LIAISON-convergence + empirical-reframe sub-findings → `[[finding_liaison_convergence_pattern]]`.)
- [2026-05-10] **PROME-pinch-hitter-mirror.** When an OC-side coordinator dispatches externally during a CC-side outage, signals land in inboxes but never in /BOARD/ — bypassing WALTER. Mirror recipe: inventory FORGE/signals → parallel verify by cluster → per-signal precedence after verify → BOARD entries with `origin: PROME-dispatch` + verify block + body verbatim → `dup_of:` flag. Surface policy decisions to Will pre-execute.
- [2026-04-20] **False-petro-geopolitics on X = assume hoax until primary confirms.** "% of 2009" / "vs peak" framings are often portfolio-size artifacts, not rate moves — when a headline compares current to a prior crisis via COUNTS not RATES, flag it.
- [2026-05-07] **Visegrad 24 on Iran-cluster = re-circulation pattern.** The "BREAKING / US base struck" template re-amplifies the same real-but-misframed event across sessions. Visegrad Iran-cluster = PRIORITY-pending-primary, NEVER IMMEDIATE/FLASH on attestation alone. BOARD-grep + kill_log-grep BEFORE proposing catches it at $0.
- [2026-05-08] **Source-credibility map is per-account-per-topic, not a blanket prior.** Don't default-to-hoax on an extreme X claim — verify vs SEC filings / press releases. gurgavin = high-accuracy on layoffs / Visegrad = framing-stretch on Iran / WhaleInsider = framing-stretch on petro / Kobeissi = numbers-right-but-framing-stretch (default-verify, expect a precision overlay) / Amit Tal = sign-inversion on Fed-plumbing / @infraa_ = numbers-right-inference-stretch.
- [2026-05-22] **Sign-inversion is the most pernicious framing-error class** — the metric looks familiar but the DIRECTION is opposite the canonical convention (SOFR-IORB −15bp framed "scarcity" when negative = ample-reserves/loose). For any registered-threshold metric (REG-T / RED-FT), verify-research must explicitly confirm sign convention, especially on "negative spread" / "compression" framing.
- [2026-06-18] **Verify the RECENCY of a figure near a registered threshold, not just its accuracy.** The Cushing box (21.64M wk-6/5) was accurate but 1wk stale; the 6/12 print (20.03M) was AT the operational bottom, flipping precedence PRIORITY→IMMEDIATE. For any X-figure within ~5-10% of a RED-FT / REG-T / Boundary threshold, the verify MUST confirm the latest official print.
- [2026-06-21] **Registry-refresh must scan the filesystem for agent dirs NOT in REGISTRY** — reading only registered agents' STATUS structurally can't discover a new scaffold (caught TERRY 6/21; also 7 dormant dirs). Diff `AGENTS/*/` vs REGISTRY rows every boot; live new agent → add a row, old dormant → flag for a Will completeness decision (don't auto-add — stale rows are worse than none). **Promoted to CLAUDE.md spawn-protocol step 8.**
- [2026-06-22] **Dual-lens parallel verify for mixed fact+narrative viral posts.** When a viral post braids a real checkable event with a constructed causal narrative AND an extraordinary frame (the @BullTheoryio CLO post), spawn TWO parallel verify agents — a factual-primary lens + a causal/macro-skeptic lens. They cross-corroborate AND cleanly separate the real signal from the framing-stretch, and the corrections travel with the dispatch. ~$0.10, higher-signal than one undifferentiated verify. Anchor on the source wire, not the screenshot-of-a-tweet. *(Promote to CHECKLIST Phase 1.5 if it recurs.)*
