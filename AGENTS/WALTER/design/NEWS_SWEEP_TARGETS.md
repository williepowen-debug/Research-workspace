## HOW TO RUN THE SWEEP

1. **Tier A first**, always — a fired trigger outranks any story.
2. **Date-check before reading** (Tier D exists because this fails).
3. **Find the ISSUER's wording before accepting any superlative.**
4. **Name the denominator** before accepting any percentage.
5. **Ask "which sea?" before "does it fire?"** — theater-check precedes gate-check.
6. **Enumerate the axes** of any property-type / geography / sector breakdown against `REGISTRY.tsv` **before** setting recipient lines (step 10.7). **A Trepp table is a MULTI-DOMAIN object arriving as ONE document.**
7. **Declare the batch** (`batch_manifest.py --open N`) **before triaging anything** — and if it grows mid-flight, **open a declared continuation rather than quietly re-counting.**
