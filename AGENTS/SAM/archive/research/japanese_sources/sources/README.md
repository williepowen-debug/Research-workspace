# Translated Sources Archive

This folder stores saved translated articles for reference.

## Naming Convention

```
[DATE]_[SOURCE]_[BRIEF_TOPIC].md

Examples:
2026-01-25_Nikkei_regional_bank_losses.md
2026-02-01_BOJ_FSR_summary.md
2026-02-10_NHK_takaichi_fiscal.md
```

## File Format

Each saved translation should include:

```markdown
# [Title in English]

**Source:** [Source name]
**Original URL:** [URL]
**Translation Date:** [YYYY-MM-DD]
**Original Language:** Japanese

---

## Summary
[2-3 sentence summary]

## Key Entities
- [Entity 1]
- [Entity 2]

## Key Numbers
- [Number 1 with context]
- [Number 2 with context]

## Tags
[Tag1, Tag2, Tag3]

---

## Full Translation

[Translated article text]

---

## Original Text (Optional)

[Japanese text if preserved]

---

*Translated via AI | Logged in TRANSLATION_LOG.tsv*
```
