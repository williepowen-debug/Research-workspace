## Base rate: does CCL preannounce?

**Answer: rarely.** CCL has strong IR discipline and runs the scheduled cadence unless something material forces a disclosure. Reviewed CCL 8-K history 2025-01 → 2026-08 (30 filings): zero pure earnings preannouncements outside the quarterly cadence. Item 2.02 filings all mapped to the four scheduled quarters. What CCL DOES file between quarters:
- **Item 7.01 (Reg FD)** — routine, mostly credit/debt disclosures (recent: 8/5 note redemption, 5/12/25 note refinancing)
- **Item 1.01 / 2.03** — new debt / credit agreements (multiple 2025 refinancings)
- **Item 5.07** — annual meeting results (routine, April)
- **Item 5.02** — officer changes

**None of those move the tape as earnings does.** For a true preannouncement (moves consensus, gaps the stock), CCL would file:
- **Item 2.02** off-cycle with revised results/guide
- **Item 8.01 (Other Events)** with an unscheduled operational update / guide change

**Neither has happened in the reviewed 20-month window.** The base rate is very low. That means: **the Q3 print itself is the near-certain vehicle for whatever CCL reveals** — not a preannouncement. This watch list therefore doubles as a Q3-print watch list.

## What the Q3 print itself will TEST (pre-registered questions)

If CRU-05 is the 30-day tape dispersion test (VX-CRU-03 forward), the Q3 CCL print is a discrete event that tests the specific-to-CCL leg. Pre-registered questions to grade the print against:

1. **FY26 net yield guide direction:** did CCL RAISE (like RCL), HOLD, or LOWER (like NCLH)? Last guide +3.2%.
2. **Fuel per metric ton (net of hedges):** actual Q3 fuel/mt. Baseline: $839 (RCL, 58% hedged) · $888 (NCLH, 52% hedged) · CCL should be materially higher if unhedged. If CCL prints ≥$920 → fuel-drag confirmed at primary. If ≤$860 → CCL has some hedging cushion CRUISE didn't know about → revise VX-CRU-01.
3. **Deposits vs prior:** Q2 $9.0B was record. Q3 should sequentially grow (booking-season pattern). A sequential DROP would be diagnostic of demand weakness.
4. **Med/Europe update:** the Q2 caveat becomes either "resolved" or "deepened." Deepened = K-shape leg for CCL.
5. **Any pull-forward vs pull-back language** on 2027 bookings (RCL said "pacing ahead of history"; NCLH said "below optimal for next 12 months"). CCL sits between.

Each answer becomes a KB row on the day of the print.
