| L-19 | 2026-08-21 | **A continuous front-month futures ticker re-points at each roll, so every delta computed across it is part contract-change — and the resulting bias in a regression coefficient runs toward ZERO, which for a "how much does X explain?" test is the flattering direction.** My load-bearing magnitude test uses an empirical gold/real-yield beta of **−0.0513 %/bp** estimated on `GC=F` daily returns. Re-estimated on the same dates against **GLD** (an unrolled proxy): **−0.0634 %/bp**, **23% steeper**, R² 0.0354 vs 0.0231. The published figure reproduces exactly on its own series (−0.0514, n=655), so this is not an arithmetic error — it is **roll noise attenuating the slope**, classic errors-in-variables. Measured contamination over 5,394 overlapping sessions: the two series' daily returns differ by **>1.0pp on 5.60% of days** and **disagree in SIGN on 13.00%**. **Why it matters in the self-serving direction:** the test says *"−6bp explains only +0.31% of a +2.83% move, so the rest is premium."* At the unrolled beta it explains **+0.38%** — a **smaller unexplained residual**. An attenuated beta systematically **OVERSTATES the premium residual**, i.e. biases my instrument toward confirming my own thesis. **Neither live conclusion flips** (8/19 is ~87% unexplained either way; the 8/7 window had yields moving the *wrong way* entirely, so a steeper beta strengthens it) — but the bias direction must be stated wherever the beta is quoted. **Rules: (a) never compute a multi-period delta or a regression across a `=F` continuous ticker without an unrolled cross-check; (b) when the two disagree, print both — and say which direction the error flatters.** | L-12/L-13 ruling session |
