## eMudhra

- [Mozilla incident 2083449](https://bugzilla.mozilla.org/show_bug.cgi?id=2083449), description and comments 5/11/13/18/19: eight intermediate signing keys affected (six TLS, two code signing); Mozilla independently recovered them. The flawed April 2025 keys used integers below 256. eMudhra preliminarily attributes this to a key-creation script and mistaken key selection. Sectigo reports cross-sign revocation. eMudhra estimates about 30,000 certificates require migration after root distrust. This is owner-reported scope and cause, not CATO cryptographic verification.
- [Mozilla security response](https://blog.mozilla.org/security/2026/10/20/protecting-firefox-users-following-the-compromise-of-emudhra-intermediate-certificates/): an attacker able to intercept connections could impersonate websites using fraudulent certificates. Standard Firefox configurations received OneCRL protection October 17; emergency software releases cover additional configurations. Android 158.0.2 adds a blocklist startup fix October 21. NSS 3.131.1 also changes trust for downstream software.
- [Original disclosure](https://emudhra.we-have-a-problem.com/): weak keys were recoverable from public certificates; many nonbrowser clients do not consume revocation updates. Historical exploitation outside Certificate Transparency-enforcing clients is unknown. Browser protection alone does not establish protection for Python, curl, package managers or containers. Root removal and intermediate revocation must cover alternate cross-signed chains; choose vendor remedies instead of improvising a blanket trust-store edit.
- [Go announcement](https://groups.google.com/g/golang-announce/c/66pojueaQek): 1.27.3/1.26.10 block affected intermediate chains (CVE-2026-111943). Installed toolchain updates alone do not demonstrate existing executables were rebuilt.
- [Node.js October release](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases): the direct page now announces available 22.23.4/24.22.1/26.12.1 updates including eMudhra certificate remediation and separate vulnerabilities. Its search preview retained the earlier prerelease notice. One separate high-severity issue is Brotli decoder remote execution, CVE-2026-111497. Keep that separate from PHP and certificate impersonation.
