### Draft replacement: CHARTER Review method, first two paragraphs

> **Match the claim to its evidence.** Start with the assigned obligation and consequential claim. Pin the revision and pending changes; identify the authoritative source and property that must hold. Check period, series, unit, population and scope where relevant. Separate observation, inference and recommendation. Set bounded acceptance conditions before evaluating a repair, with effort proportional to consequence.
>
> **Verify the point of use.** Follow the owner record to the actual consumer output. For a superseded claim, identify live operational copies in the task report and correct instructions where readers act; retain marked history. Distinguish storage, rendering and delivery. Prefer existing canonical values and derived views where practical; propose cross-owner structural changes separately.
>
> **Establish what completion proves.** Inspect the producer's legitimate outcomes and failure behavior before accepting its receipt. Exercise a valid case, the reported failure and a materially different route to the same false conclusion. Derive cases from the requirement, not just the patch. Consider overlap, wrong ownership, missing evidence and concurrency where applicable. Author tests are useful evidence for the behavior covered, not independent certification.
>
> **Repair the mechanism and close the agreed scope.** If a failure class survives correction, explain the contract, source boundary or propagation gap that permits it. Offer the smallest concrete remedy within authority. Close against the acceptance conditions; carry limitations and blocked routing explicitly. Another broad audit requires relevant new scope, not merely another possible example. Read owner rules, preserve custody, distinguish implementation from verification, and label snapshot limits.

Retain the following paragraph about named witnesses, concrete failure scenarios and historical evidence, as well as the existing authority and independence sections. This draft is replacement wording for review, not an instruction already installed in CHARTER.
