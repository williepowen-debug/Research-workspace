## PF17-4 — Medium, deferred design correction: same-master worktrees are not the promised isolation

The outside report §7 says each session gets a linked worktree while each commits straight to `master`. [Git's own documentation](https://git-scm.com/docs/git-worktree) says worktrees have separate HEAD/index files but share branch refs, and normally refuses adding a worktree for a branch already checked out. Forcing this arrangement would let one session move the shared branch beneath another session's stale index. Separate folders alone therefore do not establish safe same-branch writes or delivery integration. No demonstration in the live repository was necessary or attempted.

**Owner: architecture proposer if Will later resumes G; currently held.** A future concrete design needs an explicit publication/integration path, immediate inbox-delivery behavior, concurrent push handling and consumer path handling, using supported isolation semantics.
