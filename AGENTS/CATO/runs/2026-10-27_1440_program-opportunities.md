# Ordinary programs that could reduce agent work

## Current assessment

Will asked for initial ideas for programs that could replace agent work or improve the process, following the desktop launcher. Recommend starting with a read-only saved-research reader, then a read-only repository/machine-status companion. Both address concrete interactions already observed: retrieving what a desk wrote and asking whether local files match GitHub. Research preparation and mechanical-check presentation have larger potential but substantial existing machinery; reuse and verify it before proposing new pipelines. This is scoped exploration and advice, not authorization to build, schedule, launch agents, edit owners, or resume paused projects. No implementation remains assigned after this delivery.

The useful boundary is a checkable operation versus a judgment. Files can be located, dates compared, exact duplicates identified, arithmetic performed, and a prescribed test run by code. Source significance, definition comparability, causal interpretation, and trade construction remain owner judgment. An ordinary program can operate without LLM calls; if an agent then interprets its output, that interpretation still uses the model. No token/time savings have been measured here.
