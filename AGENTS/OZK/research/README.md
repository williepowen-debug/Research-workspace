## File Instructions

**Naming:** `[CODE]_[DESCRIPTIVE_NAME].md` where CODE is a short identifier (C1-C6 for counter-arguments, D1-D5 for deep dives, or descriptive).

**What belongs here:**
- Thesis counter-arguments and rebuttals (C1–C6)
- Deep analytical dives on specific vectors (D1–D5)
- Frameworks (8-K disclosure, insider activity)
- Any original analysis that took real work to produce

**What does NOT belong here:**
- Raw source material → `../sources/`
- One-line facts → `../workbook/KB.tsv`

**Quality bar:** Every claim should cite a KB entry or a source file. If it doesn't have a citation, it's an opinion — label it as such.

**Relationship to THESIS.md:** Research files are the supporting evidence. THESIS.md is the narrative synthesis. Findings get summarized in THESIS.md with `[KB-OZK-NNN]` anchors pointing back to KB.tsv. Research files hold the full working.
