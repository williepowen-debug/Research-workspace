## 0. Labels used

| Label | Meaning |
|---|---|
| **PRIMARY** | the figure is printed in a RealtyTrac/ATTOM release I read directly (archived realtytrac.com page via web.archive.org `id_` raw fetch, or live attomdata.com page) |
| **PRIMARY-IMPLIED** | not printed as a count; back-solved from a printed count + printed % change in a PRIMARY release. The % is rounded to whole points, so a rounding band is shown |
| **DERIVED** | arithmetic across PRIMARY counts (H1 − Q1, annual − H1 − Q3, etc.). Arithmetic shown |

| **SECONDARY** | news article quoting RealtyTrac |
| **NOT FOUND** | no printed count located |

Metric name throughout, unless flagged: RealtyTrac/ATTOM **"foreclosure starts"** = "properties that started the foreclosure process [for the first time]" = "first public notice of foreclosure, either NOD, LIS or NTS depending on the state". ## 3. Basis history — "default notices" vs "foreclosure starts" (the question asked)

| Date | What RealtyTrac printed | Evidence |
|---|---|---|
| **Q3-2011 release, Oct. 13, 2011** | Default-phase headline = **"Default notices (NOD, LIS) were filed on 195,878 U.S. properties in the third quarter"**. No "starts" count | …/third-quarter-and-september-2011-us-foreclosure-market-report-6880 (snapshot 2011-10-28) |
| **Q1-2012 release, Apr. 12, 2012** | **"First-time foreclosure starts, either default notices or scheduled foreclosure auctions depending on the state's foreclosure process"** — starts basis already in use | …-7111 |
| **Oct-2012 monthly, Nov. 15, 2012** | table footnote: **"Foreclosure Starts are the first public notice of foreclosure, either NOD, LIS or NTS depending on the state"** | …-7474 |
| **Midyear 2014, July 17, 2014** | "started the foreclosure process for the first time **(not including re-filings)**" | …-8111 |
| **Q3-2014 release, Oct. 16, 2014** | **reverted for one release** to "Default notices (LIS, NOD)" 103,179 + "Foreclosure auctions (NFS, NTS)" 139,721 — no starts count | …-8163 |
| **YE-2014 (Jan 2015) onward, and ATTOM (2016+)** | "started the foreclosure process"; YE-2014 adds "Scheduled auctions — which in some states are the foreclosure start" | …-8205; Midyear 2016 same phrasing for auctions |

⇒ **The switch to the NTS-inclusive "starts" basis happened in the public reports between Oct 13 2011 and Apr 12 2012, NOT in 2013-14.** Exact first month is not pinned (I did not read the Jan/Feb-2012 releases). **Every 2012-2016 starts figure in §1-2 is on the same NTS-inclusive, first-public-notice basis**; the only in-window exception is the Q3-2014 release, whose 103,179 is NOD+LIS only. Size of the gap, measured once: starts ≈155.6k vs default notices 103,179 in Q3-2014 = **1.51×**. **A "default notices" number is roughly two-thirds of a "starts" number in this era — never compare across the two.**

Other methodology notes that touch the basis:
- 2012-13 methodology: "if more than one foreclosure document is received for a property during the quarter, only the most recent filing is counted" — this dedup sentence is gone from the mid-2014+ methodology. It governs total FILINGS, but it is a reason not to assume quarterly counts equal summed monthlies. In practice the gap is small: Q3-2012 monthly sum 284,892 vs quarterly 284,720; Q4-2013 monthly 163,819 vs derived 163,871.
- Q1-2015: RealtyTrac "started receiving REO data from a new source" (Midyear 2015). **Affects REO, not starts**; the break date matters for any REO series.
- Company change: RealtyTrac → ATTOM Data Solutions (parent from 2016; the Oct-2016 release is ATTOM-branded). Same methodology text, same 2,139,005 peak; no starts-basis break found.
