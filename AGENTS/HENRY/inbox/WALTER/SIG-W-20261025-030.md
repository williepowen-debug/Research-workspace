## Data

[NY Fed current page](https://www.newyorkfed.org/research/college-labor-market), body/methodology read October 25, confirms **2026 Q2 recent-graduate unemployment 5.6%, underemployment 42%**. Underemployment concerns employed graduates in jobs typically not requiring degrees; it is not an unemployment add-on.

The page's legacy XLS link is a July 2023 underemployment-job-type workbook, so it cannot establish the current unemployment history. Current chart JavaScript yields this [primary CSV](https://www.newyorkfed.org/medialibrary/research/interactives/data/college-labor-market/college-labor-unemployment-data.csv), January 1990–June 2026, parsed in full. It contains **73 monthly observations before 2025** with recent-graduate unemployment above all workers. Q2 2019 averages **3.957% recent graduates vs 3.557% all workers**. This is a quarterly counterexample too.

The attached 2025 graphic's “first in 45 years” comparison therefore fails on NY Fed's current basis. This does not negate current graduate weakness, reconcile all historical vintages or demonstrate AI displacement. Original014 explicitly left the historical claim unverified; this is a verification update, not withdrawal of a previously certified claim.
