## Summary
1. One script **BREAKS** today: SAM `closeout_check.py` check F (:516-527) exits 1 after any no-change session that commits only STATUS. It is required by SAM CLAUDE.md:81 (step 15), and SAM's charter (:78) still requires an every-session re-pin. VERIFIED.
2. One script is a **latent BREAK**: VIOLET `writeback_order_check.py` :223-229 requires the pin to be among the last 30 STATUS commits. After roughly 3–4 weeks with an untouched brief, `closeout_guard.py` will block VIOLET's closeout. VERIFIED code; timing INFERRED.
3. One **conditional fail**: BOND `closeout_run.py` FAILS (rc 1) unless `--noop NEXUS_BRIEF.md "<reason>"` is passed. This is documented at BOND CLOSEOUT.md:47, so it counts as adapted.
4. **Misleading output**: VIOLET `closeout_guard.py` hides the WQ-719 EXEMPT warning when rc is 0, and RED `closeout_check.py` :570 still prints "NEXUS_BRIEF refreshed LAST".
5. **Warning only**: CORAL `boot.py` shows ⚠️ once its brief is more than 72 hours old by git age (exit stays 0).
6. **Already adapted**: `scripts/brief_pin_check.py`, VULCAN `closeout_check.py`, VIOLET `writeback_order_check.py` (except item 2), BOND `closeout_run.py` (with `--noop`).
7. Four charters still require an every-session re-pin: MARCO, ORACLE, SAM and WAL. FLG implies it. LABOR is adapted, and its CHARTER_DETAIL keeps the old text only as a marked superseded block. For scale: 26 `AGENTS/*/CLAUDE.md` files mention WQ-719, and 31 `NEXUS_BRIEF.md` files exist. I did not check that the two sets match one for one (VERIFIED counts only).
