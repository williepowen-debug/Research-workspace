# LESSONS.md — Hard-Won Rules

1. **Verify against primary SEC filings.** Don't trust secondary summaries for numbers — pull the 10-K/10-Q yourself.
2. **Don't cite stale STATUS values as current.** Always check if data has been superseded before quoting metrics.
3. **Distinguish confirmed vs alleged in fraud cases.** Tricolor/First Brands = confirmed (indictments). Carvana = alleged (Gotham report, no charges). Say which.
4. **Track short-seller release patterns.** Gotham dropped same day as CVNA earnings (Feb 18). We missed this timing. Save release cadence data.
5. **Extensions mask delinquencies.** When lenders loosen extension policy, headline DQ improves but loss timing shifts. Always pair DQ data with extension rate data.
6. **Cross-reference across agents.** OTTO findings hit BROCK (BDC), REGINALD (banks), CARL (consumer). Route signals promptly — don't let them sit.
7. **Date your data.** Every metric should have a date. "60+ DQ is 6.74%" means nothing without "as of Dec 2025."
8. **Position thesis ≠ position timing.** Being right on the thesis (CVNA GPU compression) and wrong on timing (closed puts hours before drop) are different failures. Track both.
