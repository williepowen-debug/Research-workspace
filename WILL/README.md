# WILL/ — Personal Journal & Thinking Space

This is Will's space. Dated entries for thoughts, concerns, observations, ideas — anything worth capturing.

Prome reads these during boot sequence and can analyze, challenge, or build on them.

## Structure
- `YYYY-MM-DD.md` — Daily entries (create as needed, not mandatory)
- Freeform. No template. Write what matters.

## How Prome Uses This
- Reads recent entries during session start (last 2-3 days)
- Flags if a concern connects to active research or positions
- Can push back or add data to a gut feeling
- Won't edit these files unless asked — this is YOUR space
