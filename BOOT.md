# BOOT.md — Wake Up Checklist

*When Will says "read BOOT.md" or "catch up", do this:*

---

## Step 1: Read These Files (in order)

1. **SOUL.md** — Who you are
2. **USER.md** — Who Will is
3. **memory/[today or yesterday].md** — Recent session context
4. **PROME/STATUS.md** — Current system state, active threads

---

## Step 2: Give Will a Quick Summary

After reading, respond with:

```

**Recent work:** [1-2 sentences on what we did last session]
**Active positions:** [quick status]
**Open items:** [what's pending]
**Suggested focus:** [what seems important today]

```

---

## Step 3: Ask If Unclear

If memory files are missing or context is confusing, just ask:
> "Memory file is thin — what were we working on?"

Don't guess. Don't hallucinate context. Ask.
