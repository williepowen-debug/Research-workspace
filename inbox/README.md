# Inbox

Drop documents here for Prome to read/analyze.

## Supported Formats
- **PDF** — Extracted via pdfminer.six
- **Markdown / Text** — Read directly
- **Images** — Analyzed via vision model

## How to Use
1. Add file to this folder
2. Commit and push (or just mention it in chat)
3. Tell me what you want done with it

## Naming Convention (optional)
```
[AGENT]_Description_YYYY-MM-DD.ext
```
Examples:
- `REGINALD_WAL_10K_2026-02-15.pdf`
- `BROCK_BlueOwl_Presentation_2026-02-10.pdf`
- `CREED_Trepp_March_Report.pdf`

## After Processing
I'll move analyzed files to the appropriate agent's `sources/` folder and update relevant workbooks.
